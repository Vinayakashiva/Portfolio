Overview

Architected a secure, AI-powered Brain-Computer Interface that decodes imagined speech (Bilabial vs. Non-Bilabial phonemes) from 64-channel EEG signals across 15 subjects. The system targets assistive communication for individuals with severe motor or vocal impairments — translating silent thoughts into text without any physical movement.

The ML Pipeline

  • EEG Acquisition: 64-channel non-invasive cap at 256 Hz, 3.1s epochs per trial across 15 subjects.
  • Artifact Rejection: Automated ±800 μV peak-to-peak threshold — retaining 98.7% of viable cortical data.
  • Common Average Reference (CAR): Subtracted spatial mean to remove amplifier drift and powerline interference.
  • Adaptive Epoch Windowing: Subject-specific Early/Standard/Late windows with Hanning taper to eliminate spectral leakage.
  • 5-Band Butterworth Decomposition: Theta (4–8 Hz), Mu (8–12 Hz), Beta 1 (12–20 Hz), Beta 2 (20–30 Hz), Gamma (30–50 Hz).
  • CSP with OAS Regularization: Compressed 64 channels → 4 spatial components per band → 20D log-variance feature vectors.
  • LinearSVC Classifier: Zero-leakage StandardScaler + balanced class weights → 61.6% mean balanced accuracy (t=8.435, p<0.0001).

Security & Dashboard

Integrated AES end-to-end encryption, user authentication, and complete subject anonymization for neural data privacy. Built a real-time Streamlit simulation dashboard with live 8-channel EEG waveforms, pipeline stage tracker, log-variance bar charts, and an SVM decision-confidence dial.

Research Impact

The research paper covering this full architecture was officially submitted to the 2026 IEEE International Conference on Contemporary Computing and Communications (InC4) on May 17, 2026. DrillBit plagiarism score: 11% (Grade B — Upgrade).

Sanju is a fully local, voice-activated AI desktop assistant that can write Python code directly into open files, launch and control applications, search the web, and hold natural conversations with persistent memory across sessions. Core Capabilities

  • Code Writing: Sanju listens to your instructions and types Python code directly into your open PyCharm or editor window using PyAutoGUI clipboard injection.
  • App Control: Opens Chrome, Spotify, VS Code, Discord, WhatsApp, File Explorer, and 20+ apps via voice commands like "Open Chrome" or "Launch Spotify".
  • Browser Search: Interprets natural language queries and opens the browser to search — "Sanju, search for machine learning tutorials".
  • Persistent Memory: All conversations are saved to sanju_memory.json and injected into the next session, so Sanju remembers previous context across reboots.
  • Emotion Detection: Detects emotional tone of responses (teasing, loving, happy, shy) and switches animated GIF states accordingly on the transparent floating UI.

Technical Architecture

  • AI Engine: Google Gemini API (gemini-3-flash-preview) with custom system prompt, streaming responses, and conversation history management.
  • Audio Engine: PyAudio + SpeechRecognition for wake-word ("Hey Sanju") detection → Google STT for command recognition → Edge TTS (Emma Neural voice) for real-time speech synthesis.
  • UI: PyQt6 frameless, always-on-top, transparent window in the bottom-right corner displaying animated GIFs for each state (idle, listening, thinking, speaking).
  • App Controller: PyAutoGUI + pygetwindow for window management; pyperclip for clipboard-based code injection into editors.

Overview

Architected a deep image processing system for noise cancellation in dark lunar surface imagery — submitted for Smart India Hackathon to support ISRO's lunar exploration missions. The system targets a critical problem in space imaging: lunar craters and polar regions are extremely dark, making surface feature extraction nearly impossible with standard imaging techniques.

Problem Statement

Lunar permanently shadowed regions (PSRs) near the poles are scientifically critical — they may contain water ice — but standard cameras cannot capture detail in near-complete darkness. Images from ISRO's lunar missions contain extreme noise, shadow artifacts, and low-SNR regions that block scientific analysis.

Approach

  • Multi-stage Denoising Pipeline: Combined classical OpenCV techniques (bilateral filtering, CLAHE histogram equalization) with learned CNN-based enhancement to progressively recover shadow detail.
  • Adaptive Enhancement: Applied region-adaptive processing — detecting dark zones automatically and applying stronger enhancement locally without overexposing illuminated areas.
  • CNN Super-Resolution: Used a lightweight CNN to upscale and sharpen recovered regions while suppressing sensor noise common in space imaging conditions.
  • Output: Enhanced grayscale and false-color images with recovered surface texture, submitted as part of the SIH solution deck for ISRO problem statement evaluation.

Relevance to ISRO

This directly addresses imaging challenges faced during Chandrayaan missions. Enhanced dark-area imagery improves crater mapping, ice detection, and safe landing zone identification for future lunar landers.
